# Maintaining the profile

This repo (`Vectorplayzz/Vectorplayzz`) is shown at the top of github.com/Vectorplayzz. Everything in the README is either plain text or an image generated by a script in `scripts/`, so the look stays consistent when you change things.

## Changing the page

The header, link buttons, section headings, About tiles, project cards, live-demo buttons and toolbox are generated in light and dark versions. Their content lives at the top of `scripts/build_assets.py` (`HEADER`, `ABOUT`, `HEADINGS`, `LINK_BUTTONS`, `LIVE_BUTTONS`, `CARDS`, `TOOLBOX`). Edit it, then run:

```bash
python3 scripts/build_assets.py
```

Commit the updated `assets/` folder, and update the matching `alt` text in README.md, since that is what screen readers and search engines read.

- The header's "now:" line rotates through `HEADER["rotating"]`; keep each phrase short.
- Toolbox items are either a logo slug from `scripts/icons.json` (Simple Icons, CC0) or plain text for a chip without a logo. To add a logo, copy its path and colour from simpleicons.org into `icons.json`.
- The script stops with a clear message if a card description runs past 3 lines or a toolbox row gets too long.
- It needs only Python and makes no network requests. Animations (cursor, rotating line, mosaic shimmer) stop for visitors who prefer reduced motion.

Keep each pair of cards on a single line in README.md with nothing between `</a>` and `<a`, otherwise GitHub inserts a space and the second card drops to the next row.

## Logo

`brand/logo.svg` is the profile logo: the original Vector mark (inverted triangle with an open triangle spiralling inside) redrawn on a pixel grid in the README's palette. `python3 scripts/build_logo.py` regenerates it and also writes `brand/logo-512.png`, the PNG to upload as a profile picture (needs Pillow). Tweak size, shadow or colours with the constants at the top of that script.

To set it: **github.com → your avatar → Settings → Public profile → Profile picture → Edit → Upload a photo**, choose `logo-512.png`, then **Set new profile picture**.

The previous avatar (the white mark on a dark forest photo) is kept as `avatar-original.jpg` alongside the PNG, outside this repo.

## Profile fields and repo descriptions

Already applied. If you ever need to redo them, `scripts/polish_repos.py` sets the profile name, bio and website (leaving location empty) and each project repo's description, website and topics. It previews by default and only changes things with `--apply`:

```bash
gh auth refresh -h github.com -s user        # once, lets gh edit your profile
python3 scripts/polish_repos.py              # preview
python3 scripts/polish_repos.py --apply      # apply
```

Pins (set by hand under **Customize your pins**): SITREP, OpsLoop (devops-failure-recovery-agent), Cognify, ClutchR, MiniMart, CAPTCHA Pro (worst-captcha).
